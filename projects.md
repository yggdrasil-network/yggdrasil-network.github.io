# Projects

The following projects have been built with the Yggdrasil Network at their core. If you know of a project that belongs here, please feel free to [open a pull request on GitHub](https://github.com/yggdrasil-network/yggdrasil-network.github.io/edit/master/projects.md).

----

## Communication

### Yggmail

End-to-end encrypted email for the mesh networking age. Each Yggmail node is assigned an email address based on its public key and the mailbox can be accessed using standard IMAP and SMTP protocols.

[GitHub repository](https://github.com/neilalexander/yggmail)

### Mimir

A clean, privacy-focused messenger that puts you back in control of your communication. Supports text messages, group chats, pictures, and audio calls.

[Website](https://mimir.im), [GitHub repository](https://github.com/Mimir-IM/mimir)

### Zen

A messenger and social network with no servers, no ads and no algorithm, encrypted end to end and resistant to quantum computers. Supports chats and calls, friend graph, feeds, videos and more.

[GitHub repository](https://github.com/robertostrowskijagoda/Zen)
